# Kantima | Web Developer Portfolio

A personal portfolio website built with React.

The portfolio displays my projects, technical skills, and information about me. Project and technology data are retrieved from the Express API.

## Live Website

https://kantima-portfolio.vercel.app/

## GitHub Repository

https://github.com/EmmeyKantima/kantima-portfolio

## Assignment 1 API

The React application retrieves data from the backend API created in Assignment 1.

- Projects API: https://admin-portfolio-uvw4.onrender.com/api/projects
- Technologies API: https://admin-portfolio-uvw4.onrender.com/api/technologies

## API Integration

The website uses the Express API from Assignment 1 to retrieve project and technology data.

The API URL is stored in an environment variable:

`VITE_PORTFOLIO_API_URL`

This keeps the API configuration separate from the React components.
